# Architecture decision records

Each ADR records one decision: its context, what was decided, and the consequences. Copy
[`0000-template.md`](0000-template.md) to start a new one, give it the next number, and
open it with Status: Proposed. An accepted ADR is not edited to change its decision; a
new ADR supersedes it.
